# Revamped AKHIT

A homepage-only redesign for AKH IT Solutions, built as a static site. It uses the project imagery and client logos from the supplied AKH redesign website, with the approved teal palette and one sans-serif font family.

## Preview

GitHub Pages: https://avinashgit26.github.io/revamped-akhit/

The site lives in `site/`. Navigation to service, portfolio, careers, about, privacy and contact pages points to the existing redesign website. Only the homepage is hosted in this repository.

## Publish

The `Deploy GitHub Pages` workflow publishes the `site/` directory whenever changes reach `main`.
